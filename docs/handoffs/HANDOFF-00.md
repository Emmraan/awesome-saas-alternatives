## Decisions

- **Branch-per-phase honoured, even for the root commit.** P0 was committed on
  `phase/00-repo-foundation` and merged into `main`. Git refuses to squash-merge
  into an empty head (`fatal: Squash commit into empty head not supported yet`,
  verified), so the root commit used a **fast-forward merge** — the closest the
  protocol allows for a first commit. The phase branch was deleted after merge.
  From P1 onward, `git merge --squash phase/NN-name` applies exactly as PLAN.md
  describes.

  `packageManager` (pnpm) land in `package.json` in P1.
- **`tsconfig incremental: true`** belongs to P1 (`tsconfig.json` owner); the
